# 🎁 Componente Frontend - Plataforma Oficial Donatón

Este directorio contiene la aplicación cliente y la interfaz de usuario para el sistema **Donatón**. El componente ha sido empaquetado bajo el estándar riguroso de **Node Package Manager (NPM)** y utiliza **React** con **Vite** para garantizar una renderización reactiva de alta velocidad.

## 🛠️ Estructura del Componente
* `package.json`: Archivo de configuración NPM con las dependencias y scripts obligatorios de ejecución.
* `src/`: Directorio de código fuente unificado.
    * `src/App.jsx`: Tablero de control reactivo integral. Conecta los flujos visuales con las API REST del Backend.
* `public/`: Recursos públicos e íconos estáticos del sistema.
